Cara Menjalankan Program

## Pastikan Python 3 telah terpasang pada perangkat.

Buka terminal atau Command Prompt.

Masuk ke direktori folder proyek.

Jalankan program sesuai nama file menggunakan perintah berikut:

python tugas1_bmi.py
python tugas2_nilai_mahasiswa.py
python main.py

Kesimpulan

Melalui praktikum ini, konsep dasar pemrograman Python diterapkan dalam beberapa program sederhana. Program pertama menerapkan variabel, input, operasi aritmatika, dan percabangan. Program kedua menerapkan list, dictionary, perulangan, serta pengolahan data mahasiswa. Sementara itu, program ketiga menerapkan konsep fungsi dan modularitas melalui pembuatan serta penggunaan modul Python kustom.

Dengan demikian, praktikum ini memberikan pemahaman mengenai cara menyusun program Python secara terstruktur, mengolah data, serta menggunakan kembali fungsi melalui modul yang dibuat sendiri.
